接入 · MCP

挂进你的 AI，用说的：「把这个 HAP 装到手机上」。

HapLane 是 MCP 工具——不用背命令，agent 自己选工具、撞错自己修。粘一段配置就接上，支持任意 MCP 客户端。

1 · 下载 MCP（Gitee 直连，不走 npm）
haplane-mcp.mjs ⬇　放到本地任意路径
2 · 粘进你的 MCP 配置
{ "mcpServers": { "haplane": { "command": "node", "args": ["/你的路径/haplane-mcp.mjs"] } } }
或 · 已上 npm，也能用 npx（你的 npm 走 npmmirror 时国内更快）
"command": "npx", "args": ["-y", "-p", "haplane", "haplane-mcp"]
3 · 在 AI 里直接说
「帮我把 ./app.hap 签名装到手机」——agent 自己调 deploy_to_device，撞 system 权限自动降级重装，装完验签。

也能命令行直接用

一条 deploy 搞定，也能拆成四步。

不挂 MCP、想手动跑也行。deploy 一条龙：签名 + 装机 + 验签。只想签名、或只想推包？拆开单独调那一步就行。

命令做什么要连设备？
haplane deploy --in app.hap签名 → 装机 → 验签，一条龙（带 --in 跳过打包）要（装机那步）
haplane deploy从源码工程全链：hvigorw 打包 → 签名 → 装机 → 验签要
haplane sign --in app.hap只签名，产出签好的 HAP上架 / CI 不用；debug 真机连一次取 UDID
haplane install --in app.hap只推已签好的包（≈更聪明的 hdc install）要
haplane verify --in app.hap只验签名，判真假不用
haplane setup / doctor / device生成配置 / 体检工具链 / 列设备取 UDIDdevice 要
手动 vs 一键

签名墙不是难，是"烦"——每一步都能卡你半天。

HoKit、小白助手是把这些步骤塞进界面里一个个点；HapLane 是一条命令跑完，还能写进脚本、让 AI 帮你跑。

⚠ 老实说

它不做什么，和你需要准备什么。

签名这件事，本来就该在你有权限的范围内做。HapLane 不碰灰色地带，也不藏着前提。

不做

  • 不破解、不绕过签名——只帮你把该走的流程走顺
  • 只处理你自己或已授权的设备 / 账号
  • 不碰纯血鸿蒙真机的商用根：真机走你自己的 AGC 材料

前提

  • 华为开发者账号 + AGC（真机 / 上架签名要）
  • 华为 SDK：hdc / hap-sign-tool / java（各平台官方版都有）
  • Node（或用单文件二进制）；macOS / Windows / Linux 都行
